# AriGit
 AriGit is a lightweight version control system that provides essential Git functionalities, including repository initialization, file staging, commit tracking with messages, commit history viewing, and version diffs. Designed for simplicity and efficiency, AriGit offers fundamental version control capabilities while maintaining a minimalistic approach.
